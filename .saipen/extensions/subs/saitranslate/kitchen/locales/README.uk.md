# Problip Android

Нативный Android-порт [Problip](reference/windows/Problip.cs) — маленький таймер медитации со случайными звуковыми сигналами. Windows-версия — поведенческий ориентир, а не исходник для переноса.

- Бренд: **Problip**
- Название в Google Play: *Problip: Random Beep Timer*
- Идентификатор приложения: `com.vacster.problip`

## Стек

- Kotlin, Jetpack Compose, корутины, DataStore, AndroidX AppCompat (языки на уровне приложения)
- Play Billing 9.1.0 (только разовые покупки — без подписок)
- Gradle Kotlin DSL, каталог версий
- compileSdk 36, targetSdk 36, minSdk 26
- один модуль `app`

## Что делает приложение

- **Сессия**: START проигрывает первый сигнал примерно через 500 мс и продолжает до STOP. Один foreground-сервис, один планировщик, один аудиодвижок — никогда не два.
- **Интервалы**: случайные 4–7 с (бесплатно), фиксированные 5/10/15/20/30 с (бесплатно) плюс два премиум-пресета — **MANUAL** (свои FROM/TO в секундах, границы 1–3600, упорядочиваются) и **PULSE** (5 с, затем новый случайный 10–20 с, чередуются).
- **Звуки**: шесть звуков, один бесплатный; случайный пул выбирает только из тех, что могут звучать.
- **Темы**: **15 палитр Wintage** (1 бесплатная + 14 премиумных), мгновенное переключение, одна светлая (Vintage Classic). Пресет `Custom` из архива дублировал Golden Default и был удалён; сохранённый выбор `theme_wintage_custom` разрешается обратно в Golden Default.
- **Пробные периоды**: любой неприобретённый премиум-звук, тема или пресет интервала может запустить **пятиминутную пробу** — многоразовую, на каждый элемент, с сохранённым «настенным» сроком истечения. Без кулдаунов, аккаунтов, идентификаторов устройства и серверных проверок.
- **Статистика и награда**: считаются только реально успешные сигналы (сегодня / неделя / месяц / всего — в настройках и строкой `BLIPS n` на главном экране, её можно скрыть). На **100 000** успешных сигналов Premium открывается локально и навсегда — отдельный источник доступа `EARNED`, который не меняет владение в Play и не отменяется сбросом, возвратом средств или обновлением Billing.
- **Blip Glow**: премиумная мягкая пульсация акцента на фоне главного экрана при каждом успешном сигнале (максимум 25% альфы). Едет с Customization Pack, собственной пятиминутной пробой `feature_blip_glow`, Developer Access или заработанной наградой; по умолчанию включена и ничего не скрывает, кроме самого эффекта.
- **Developer Access**: скрытая семидневная глобальная разблокировка через аккорд на заголовке PROBLIP (держать ~20 с, затем START/STOP не отпуская). Подпись — `DEV`, никогда `OWNED`: доступ истекает, покупка — нет.
- **Виджет**: компактный виджет START/STOP на домашний экран, следует реальному состоянию сессии, без опроса и второго планировщика. Основной размер 1x1 (знак бренда + статус + большая поверхность START/STOP), растягивается к 2x1/2x2; слово PROBLIP появляется там, куда лаунчер сообщает о достаточной ширине.
- **WakeLock**: один `PARTIAL_WAKE_LOCK` (`Problip:ActiveSession`) во владении сервиса, удерживается только в RUNNING — без него процессор засыпал между сигналами, и 5-секундный интервал превращался примерно в 20 с.
- **MINIMIZE**: явная кнопка — уводит приложение в фон, не останавливая сессию.
- **EXIT**: явная кнопка того же уровня; живая сессия (STARTING/RUNNING) сначала останавливается обычным путём сервиса, затем задача закрывается (`finishAndRemoveTask`). STOPPED/ERROR выходят без касания сервиса. Никаких `System.exit` и `killProcess`.
- **Справка**: `?` в шапке главного экрана открывает один диалог в стиле Wintage (прокручивается внутри, сам главный экран не прокручивается) — быстрый старт, интервалы, премиум/пробы, фон, советы, FAQ. Скрытый жест Developer Access сознательно не документирован.
- **Языки**: английский (по умолчанию), русский, эстонский, японский плюс системный, выбор в строке LANGUAGE настроек через `AppCompatDelegate.setApplicationLocales` (сохраняет AppCompat; `generateLocaleConfig` включён, комплектуемые языки закреплены: en/ru/et/ja). Сервис, уведомление и виджет разрешают строки через ту же переопределённую локаль.

Всё премиумное едет на двух продуктах Play (премиум-звуки и один Customization Pack); правило доступа одно и в одном месте:
`free || owned || activeTrial || developerAccess || earnedPremium`.

## Сборка

Идентичность релиза: **versionName 1.0.0, versionCode 1** (`app/build.gradle.kts`).
После первой выгрузки в Play каждая следующая требует строго большего versionCode — см. `docs/release-checklist.md`.

Нужны JDK 17+ и Android SDK с platform 36.
Укажите SDK в `local.properties` (`sdk.dir=...`).

```bash
./gradlew assembleDebug
./gradlew test
./gradlew bundleRelease        # app/build/outputs/bundle/release/app-release.aab
```

Релизные артефакты собираются **неподписанными**, пока неотслеживаемый `keystore.properties` не даст секреты подписи (`docs/release-signing.md`) — неподписанный релиз хорош для локальной проверки и никогда не годится для боевой выгрузки. Минификация для v1.0.0 остаётся выключенной: включение R8 — это дельта поведения под перепроверку, а не релизный шаг.
